📐 Quick Formula Reference

Netzeingabe & Vorwärtsdurchlauf (einzelnes Neuron)

z = w₁x₁ + w₂x₂ + ... + wₘxₘ + b = wᵀx + b
a = a(z)  ·  linear: a(z)=z  ·  logistic: a(z)=1/(1+e⁻ᶻ)

Verlustfunktionen

MSE: L = (1/n) ∑ (a⁽ⁱ⁾ − y⁽ⁱ⁾)²
BCE: L = −(1/n) ∑ [ y⁽ⁱ⁾ ln(a⁽ⁱ⁾) + (1−y⁽ⁱ⁾) ln(1−a⁽ⁱ⁾) ]

Gradientenabstieg – Aktualisierung

w₋ᵏ⁺¹₍ = w₋ᵏ₍ − η · ∂L/∂w  ·  b₋ᵏ⁺¹₍ = b₋ᵏ₍ − η · ∂L/∂b

MLP-Vorwärtsdurchlauf (eine verdeckte Schicht)

z¹ = W¹x + b¹  ·  a¹ = a(z¹)
z² = W²a¹ + b²  ·  a² = a(z²) = ŷ

Aktivierungsfunktionen

Sigmoid σ(x)=1/(1+e⁻ˣ)  ·  tanh(x)  ·  ReLU=max(0,x)
Leaky ReLU, ELU · Softmax(z)ₖ = eᶻₖ / ∑₃ eᶻ₃

Verschwindende Gradienten

max σ′(x) = 0,25 → tiefe Sigmoid-Ketten schrumpfen den Gradienten ≈ (0,25)ᴸ
