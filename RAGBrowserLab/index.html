How it works: your question is embedded in‑browser and matched against the corpus by cosine similarity and BM25 keyword scoring; the two rankings are fused with Reciprocal Rank Fusion (rank k·3 candidates, score = Σ 1/(kRRF+rank)). The top chunks go into the same anti‑LaTeX prompt as the notebook, your selected Ollama model answers locally, and any leftover LaTeX is converted to Unicode.

Setup guide — Ollama for the RAG Browser Lab

    
Everything in this page runs locally in your browser except the final LLM call, which goes to Ollama on your own machine. Three steps: install Ollama, pull a model, allow this page to talk to it.


    

      
      
      
    


    
    

      
① Install Ollama

      
Download OllamaSetup.exe from ollama.com/download/windows and run it. Then verify in PowerShell:

      
ollama --version

      
② Pull the models

      
mistral (~4.1 GB) is the default, but any Ollama model works — the model dropdown in the app lists everything you have pulled. Add a smaller one for speed or a bigger one for quality.

      
ollama pull mistral

      
ollama pull llama3.2

      
ollama list

      
③ Connect this page (CORS)

      
1. Quit Ollama: right‑click the llama icon in the system tray → Quit Ollama (otherwise it restarts itself without the setting). Then force‑stop any leftover server:

      
taskkill /F /IM ollama.exe

      
2. Allow this page (same PowerShell window, no restart needed):

      
$env:OLLAMA_ORIGINS="*"

      
3. Start the server — keep this window open while you use the lab:

      
ollama serve

      
Check: echo $env:OLLAMA_ORIGINS should print *. If step 3 says the port is already in use, an old server survived — repeat step 1 and make sure the tray app is quit. Finally click Connect in the app header.

    


    
    

      
① Install Ollama

      
Download the app from ollama.com/download/mac, unzip and drag it into Applications — or with Homebrew:

      
brew install ollama

      
ollama --version

      
② Pull the models

      
ollama pull mistral

      
ollama pull llama3.2

      
ollama list

      
③ Connect this page (CORS)

      
Simplest (one‑off, Terminal): quit the menu‑bar app first (llama icon → Quit Ollama), then run — and keep the Terminal open:

      
OLLAMA_ORIGINS="*" ollama serve

      
Persistent (menu‑bar app): set the variable system‑wide, then quit and reopen the Ollama app:

      
launchctl setenv OLLAMA_ORIGINS "*"

      
Then click Connect in the app header. (The launchctl setting lasts until reboot; run it again after restarting the Mac, or use the one‑off variant.)

    


    
    

      
① Install Ollama

      
curl -fsSL https://ollama.com/install.sh | sh

      
ollama --version

      
② Pull the models

      
ollama pull mistral

      
ollama pull llama3.2

      
ollama list

      
③ Connect this page (CORS)

      
Simplest (one‑off): stop the background service, then run in a terminal you keep open:

      
sudo systemctl stop ollama

      
OLLAMA_ORIGINS="*" ollama serve

      
Persistent (systemd service):

      
sudo systemctl edit ollama

      
Add these lines in the editor that opens, then save:

      
[Service]
Environment="OLLAMA_ORIGINS=*"

      
sudo systemctl daemon-reload && sudo systemctl restart ollama

      
Then click Connect in the app header.
